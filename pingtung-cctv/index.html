📹 屏東市道路即時影像

集中看屏東市各路口、省道、國道的即時路況攝影機畫面，也能在「🚗 路線＋天氣」查出門路線沿路會不會下雨。資料來自交通部 TDX 運輸資料流通服務（屏東縣市區道路、公路局省道、高公局國道），在瀏覽器裡直接讀取，不經過其他伺服器。

🔑 TDX 金鑰（選填，畫面抓不到時再設定）

不填金鑰也能用，但 TDX 對未登入的連線每天有呼叫次數限制。若出現「次數已用完」或「需要金鑰」，可到 TDX 運輸資料流通服務 免費註冊，在「會員中心 › 資料服務 › API 金鑰」取得 Client ID 與 Client Secret 填在這裡。攝影機清單會在瀏覽器暫存 6 小時，平常一天只會呼叫幾次。

點畫面可放大看即時串流；看不到時按「↗ 原始畫面」。

    • 起點、終點的預設位置是依地址估的大略位置，若不準可按「地圖上點起點／終點」修正，會記在這台裝置。

    說明與其他官方路況網站

    • 縣市道路：屏東縣政府提供給 TDX 的市區路口攝影機。省道：交通部公路局（台1線、台3線、台24線、台27線、台88線等）。國道：高速公路局（國道3號）。
    • 「屏東市」範圍是依座標框出屏東市區的大略範圍；「全屏東縣」用縣界的近似範圍篩選省道與國道，邊界附近可能多出或少掉幾支。
    • 畫面由各管理機關的攝影機直接提供；鏡頭維修、斷線或機關不允許其他網頁內嵌時會顯示「目前無法顯示」，可改按「↗ 原始畫面」開新分頁看。
    • 同一個網站的串流一次只能開幾條連線，所以影像牆只播放畫面上看得到的攝影機，捲走就會停止。
    • 官方網站：公路局 168 智慧化省道即時資訊服務網、高速公路局 1968 路況、屏東縣政府。
