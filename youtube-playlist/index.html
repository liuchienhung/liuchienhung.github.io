▶️ YouTube 播放清單轉網址清單

把整個播放清單一鍵轉成一行一個的影片網址，直接貼進 Gemini Notebook（NotebookLM）當來源。全部在瀏覽器裡處理，不經過任何伺服器。

① 取得播放清單裡的影片

YouTube 不允許其他網站直接讀取播放清單，所以用「書籤小工具」在 YouTube 頁面上幫你收集：

  1. 把下面這顆按鈕拖曳到瀏覽器的書籤列（手機或無法拖曳時，見下方「手動建立書籤」）：
    ▶ 播放清單轉網址
  2. 打開 YouTube 播放清單頁（網址含 list=，例如 youtube.com/playlist?list=…，或正在播放清單中的影片頁）。
  3. 點一下書籤。它會自動往下捲動載入全部影片，完成後跳出視窗，按「複製全部網址」就能貼進 Gemini；或按「在轉換工具開啟」回到這頁做分批、挑選。
手動建立書籤（手機／拖曳不了時）

新增任一書籤，把書籤的「網址」改成下面這段文字（整段複製）：

手機 Chrome：打開 YouTube 播放清單後，在網址列輸入書籤名稱，點選書籤建議即可執行。

貼上任何含有 YouTube 影片網址的文字，會自動抓出所有影片（自動去除重複、保留順序）。例如：

  • 在播放清單頁全選（Ctrl/⌘+A）複製後貼上，或把多個影片網址一次貼上
  • 在播放清單頁按右鍵「檢視網頁原始碼」整頁貼上（可能混入推薦影片，貼上後可在下方取消勾選）

有 YouTube Data API v3 金鑰的話，貼上播放清單網址就能直接讀出全部影片與標題（公開或不公開的清單都可以）。

怎麼取得 API 金鑰？
  1. 到 Google Cloud Console 建立專案，啟用「YouTube Data API v3」。
  2. 在「憑證」建立 API 金鑰；建議限制只能用 YouTube Data API v3，並把網站限制設為本站網址。
  3. 每讀 50 部影片約用 1 單位配額，每日免費 10,000 單位，個人使用綽綽有餘。

② 複製網址，貼進 Gemini Notebook

Gemini Notebook／NotebookLM：「新增來源」→ 選「YouTube」或「網站」→ 貼上網址（可一次貼多個，用空白或換行分隔）。每個筆記本的來源數有上限（如免費版 50 個），清單很長時可分批貼到不同筆記本。
