# 資通安全題庫線上測驗系統

## 系統簡介

這是一個基於HTML、CSS和JavaScript開發的多服務入口，目前包含「資通安全題庫線上測驗」、「AI應用規劃師(中級)題庫模擬測驗」、「原版試卷報讀」、「康軒國語首冊注音練習遊戲」、「注音筆順小火車」、「數學小火車（翰林一上）」、「衣服尺寸建議」與 Codex Pets Demo。AI 應用規劃師(中級)已獨立為服務，依科目一、科目二學習指引章節建立單選題庫，每科各 1000 題，並參考 114 年第二梯次公告試題的情境式出題方向。

## 功能特色

### 🎯 核心功能
- **多單元測驗**：包含7個滲透測試相關單元
- **科目選擇**：可在「資安概論」與「系統及網站滲透測試」間切換
- **單題顯示**：預設每次1題，可自行調整每頁題數
- **即時互動**：點擊選項即時選擇，支援修改答案
- **自由切換**：未答題目亦可切換上一題或下一題
- **倒數計時**：預設30分鐘，到時自動提交
- **自動評分**：測驗完成後自動計算分數和正確率
- **通過提示**：測驗結束時依分數顯示通過或未通過，並提示通過分數（滿分100分，70分及格）
- **進度提示**：進度條搭配中央進度文字顯示目前題號與總題數
- **答案顯示**：提交後顯示正確答案，錯誤選擇以紅色標記，正確答案以綠色標記
- **隨時結束作答**：按下「結束作答」會再次確認，確定後立即交卷並計算成績
- **題目收藏**：可標記星號以利後續檢視
- **答題狀態檢視**：列表顯示已答與未答題目並可快速跳轉，交卷後以勾叉標示正確與否
- **匯入單選題庫**：可將JSON檔案匯入至指定單元
- **匯出單選題庫**：下載指定單元的題庫JSON
- **匯入多選題庫**：支援多選題JSON匯入
- **匯出多選題庫**：下載多選題JSON
- **匯入全部單選題庫**：一次匯入所有單選題庫
- **匯出全部單選題庫**：下載目前科目所有單選題庫
- **匯入全部多選題庫**：一次匯入所有多選題庫
- **匯出全部多選題庫**：下載目前科目所有多選題庫
- **多選題範例格式下載**：提供多選題匯入JSON範例
- **自訂科目與單元**：介面提供新增及刪除科目，並在檔案管理區新增或移除單選及多選題庫的單元
- **編輯單選題庫**：可在指定單元中勾選並刪除題目
- **多選題測驗**：支援各單元獨立測驗及全部單元綜合測驗
- **結果匯出**：測驗完成後可下載包含題目與答案的PDF報告
- **響應式設計**：支援桌面和行動裝置
- **Bootstrap 5 控制區**：按鈕區塊使用 Bootstrap 5 重新排版，並加入進度條
- **設定選單**：單元設定頁新增設定圖示，點擊後開啟檔案匯入匯出與單元管理操作
- **標準化PDF**：匯出的PDF採用A4並套用Word標準邊界

### 📚 題庫內容
* **資安概論**：含2個示範單元
* **系統及網站滲透測試**：含7個單元
    1. **第一單元：滲透測試簡介** (15題)
    2. **第二單元：資訊蒐集** (5題)
    3. **第三單元：網路、主機及網站掃描** (5題)
    4. **第四單元：弱點利用** (5題)
    5. **第五單元：提升權限** (5題)
    6. **第六單元：維持存取權限** (5題)
    7. **第七單元：整理漏洞與撰寫報告** (5題)
    8. **全部單元綜合測驗** (45題)
* **AI應用規劃師(中級)題庫模擬測驗**：獨立服務，含2個科目，共2000題單選題
    1. **第一科：人工智慧技術應用與規劃** (1000題)
    2. **第二科：大數據處理分析與應用** (1000題)
    3. **各科目全部單元綜合測驗** (每科1000題)

* **原版試卷報讀**（`pdf-reader/`）：獨立靜態頁面，上傳試卷 PDF 後依原檔版面朗讀
    - **版面不調整**：以 pdf.js 直接把 PDF 原頁面繪在畫布上，頁面框的長寬比固定為原檔尺寸，只能等比例放大縮小，不重排文字、不改字距行距與圖片位置；點讀與高亮畫在上方的透明圖層
    - **點讀**：點選卷面文字念出該句；選項 ①②③④ 各自為一個點讀單位；開啟「⬚ 框選」可拖曳框出範圍，只念框內文字
    - **連續朗讀**：▶ 從目前位置一路念到最後一頁，可上一句／下一句／再念一次，並自動捲動到朗讀位置；鍵盤：空白鍵播放暫停、←/→ 上下句、R 重念、Esc 停止
    - **閱讀順序**：自動判斷直書（由右而左、由上而下）或橫書，處理上下分半版面、跨欄句子、作答括號「（　）」（念「空格」）、直書中的橫向數字與頁碼
    - **注音試卷**：辨識注音字型（如 StdKaiZuinn、ZhuYinNR）。「看注音寫國字」只顯示注音的格子念出讀音、字幕顯示〔注音〕，不洩漏國字；「看國字寫注音」以「」框住且沒有附注音的國字，預設以「這個字」代替，不念出讀音（可在設定中改為照念）
    - 標點符號選擇題的選項（①、②，）會念出「頓號」「逗號」等名稱
    - 題號（1、(1)、1.、連連看的ㄅㄆㄇ標號）與題目內容之間會停頓、字幕空一格，並從題號處另起一句
    - **讀音修正**：瀏覽器語音遇到破音字可能念錯（如「抹布」念成ㄇㄚ布），可在「⚙️ 設定 › 讀音修正」或字幕列的「讀音不對？」設定「原詞 → 念成」（以同音字代替），只影響朗讀、不改卷面與字幕；預設內建「抹布 → 摸布」
    - 檔案只在瀏覽器本機處理不上傳；語速、語音與設定記在瀏覽器。需要 PDF 內含文字層（掃描圖檔會提示無法點讀）

* **注音小火車大冒險（康軒國語首冊）**（`kangxuan-chinese/`）：獨立靜態頁面，依 115 學年度康軒一上首冊 9 課編排成 9 個「火車站」
    1. **🚂 火車進站**：火車載著注音車廂進站，聽音點對的車廂，答對火車嘟嘟開走
    2. **🪱 挖蚯蚓**：蚯蚓、甲蟲從泥土洞冒出來舉著注音牌，聽音抓對的蟲放進水桶；點空洞會挖出泥土
    3. **🐢 餵小烏龜**：小烏龜說想吃什麼（香蕉、蘋果、地瓜、薯條、吳郭魚、蚯蚓…），選出寫著正確拼音的葉子餵牠
    4. **🚃 拼音火車**：照順序把注音符號裝進車廂，最後一節選聲調
    5. **🪲 甲蟲飛飛**：選聲調後甲蟲照聲調的形狀飛（一聲平飛、二聲往上、三聲先下再上、四聲往下），飛對就吃到蘋果
    6. **📖 注音卡**：點卡片聽符號與代表字
    - 只出現「已學過的符號與聲調」組成的詞；孩子喜歡的詞（火車、泥土、烏龜、甲蟲、蚯蚓、香蕉、蘋果、地瓜、薯條、馬鈴薯、吳郭魚）出現機率較高，並在地圖上顯示每站「新解鎖」的詞
    - 獎勵：每站每個遊戲的最佳星數、24 張貼紙寶貝箱（火車、昆蟲、食物）、隨星星長大的小烏龜（可取名）；Web Audio 合成音效，可關閉
    - 家長設定（⚙️）：累積複習、注音念法（相近國字／直接念符號）、🎙️ 自己錄發音（存於該裝置 IndexedDB，遊戲優先播放）、調整各課課名與符號、清除進度；資料都只存在瀏覽器
    - 第 1～3 課課名與符號依康軒首冊（〈貓咪〉、〈鵝寶寶〉、〈河馬和河狸〉）；第 4～8 課符號分組未能對照實體課本確認，可在設定中修改或改頁面中的 `DEFAULT_LESSONS`

* **注音筆順小火車**（`zhuyin-stroke/`）：獨立靜態頁面，37 個注音符號在田字格裡練筆順，車站分組同康軒首冊課次
    1. **👀 看筆順**：帶路的小幫手（🚂 嘟嘟號、🪲 甲蟲、🐢 龜龜、🪱 蚯蚓，可在設定切換）沿著筆畫走，筆畫跟在後面長出來，並念出「第一筆，撇橫折鉤」
    2. **✍️ 描描看（⭐）**：淡淡的字上顯示綠色起點號碼、會流動的虛線箭頭，終點放著香蕉、蘋果、地瓜、薯條、馬鈴薯、吳郭魚或蚯蚓，孩子用手指從起點描到食物；寫錯 2 次自動示範這一筆
    3. **🌟 自己寫（⭐⭐～⭐⭐⭐）**：只有田字格，一筆一筆判斷；寫錯幾次（可設定）才給箭頭提示，全部沒寫錯得 3 顆星
    - 判斷每一筆是否從起點開始、照方向寫到終點並沿著筆畫走，會提示「方向反了」「起點不對」「還沒寫完」等
    - 寫完龜龜吃到點心、彩帶掉下來；首頁的龜龜隨星星長大，每個符號 3 顆星換一張貼紙（📒 貼紙本）
    - **🖨️ 列印練習單**：列印目前車站的田字格練習單（筆順分解、描紅、空白格）
    - 筆順與字形資料來自教育部「國字標準字體筆順學習網」的注音符號筆順（經 [g0v/zh-stroke-data](https://github.com/g0v/zh-stroke-data) 整理，存在 `zhuyin-stroke/strokes.js`）；小朋友名字預設「大寶」，紀錄只存在瀏覽器

* **數學小火車（翰林一上）**（`hanlin-math/`）：獨立靜態頁面，依 115 學年度翰林版國小數學一上 9 個單元設計成 9 個火車站，以孩子喜歡的火車、挖蚯蚓、玩泥土、烏龜、甲蟲與香蕉、蘋果、地瓜、薯條、豆腐、吳郭魚為題材
    1. **蚯蚓田站（10以內的數）**：挖開土堆數蚯蚓、點食物裝上火車再出發、點車廂比大小與認國字
    2. **泥巴路站（比長短）**：點最長／最短的蚯蚓、用薯條量蚯蚓、疊豆腐比高矮、比書的厚薄、比火車長短、誰挖的蚯蚓最長
    3. **烏龜賽跑站（順序與多少）**：火車第幾節車廂坐誰、烏龜賽跑看名次、兩種食物比多少
    4. **豆腐店站（分與合）**：葉子下藏了幾塊豆腐、吳郭魚分給兩隻烏龜、數的組成圖（含 0 的認識）
    5. **甲蟲森林站（認識形狀）**：幫甲蟲找出所有三角形等平面圖形、找出像球／罐子／箱子或可以疊高的東西、拼一拼（可拆開看用了幾個什麼形狀）、送貨到形狀倉庫
    6. **上車站（10以內的加法）**：月台上的甲蟲上車、再挖幾條蚯蚓放進桶子、加法算式
    7. **烏龜餐廳站（10以內的減法）**：親手餵烏龜吃掉幾個再算剩下、比較誰挖得多、減法算式
    8. **蚯蚓罐頭站（30以內的數）**：每 10 條蚯蚓裝一罐、車廂號碼順序與比大小、十位個位
    9. **時鐘塔站（認識時間）**：撥時鐘讓火車出發、看時鐘說時間、選出正確的時鐘
    - 每站 8 題，另有「🎲 大冒險」（各站混合 10 題）與「⚡ 火車衝衝衝」（60 秒 10 以內加減）
    - 答錯可再試一次，第二次會顯示解說；一次答對越多星星越多。答對得到食物，可到「🐢 烏龜池」餵小龜讓牠長大；每站拿 2 顆星解鎖一張甲蟲卡
    - 可在設定中改小朋友名字（預設「大寶」）與是否自動念題；所有紀錄只存在瀏覽器
    - 單元小節參考均一教育平台「類翰林版」一年級（https://www.junyiacademy.org/topics/h-m1a）；若課本單元不同，可修改頁面中的 `UNITS` 與各關卡函式

* **衣服尺寸建議（胸寬・衣長）**（`clothing-size/`）：獨立靜態頁面，量身體後建議適合的衣服胸寬與衣長，並對照商品尺寸表選尺寸
    - **📷 相機即時量測**：MediaPipe Pose（full 模型＋人形輪廓）取得頭頂到腳底高度，依輸入的身高換算公分；量胸部高度（肩→髖 30%～40%）輪廓寬度得到胸部正面寬，側面再量胸部厚度（選填，沒量用正面寬 × 0.72、孩子 × 0.8 估計），以橢圓周長 × 1.05 估算胸圍；肩頸點到胯下（兩腿間輪廓最高點）作為衣長基準。有倒數與語音提示，可一個人操作；也可上傳正面／側面全身照
    - 會檢查全身入鏡、面向／側身、手臂離開身體、站直，不合格會提示怎麼調整；收集多張畫面取中位數
    - **✍️ 手動輸入**：身高、胸圍（皮尺）、肩頸點到胯下（選填，空白依身高估算）；或 **👕 量一件合身的衣服** 的胸寬與衣長
    - **建議**：依種類（T恤、襯衫／POLO、帽T、外套）、版型（修身～Oversize 的放鬆量）與衣長（短版／標準／長版）算出建議胸寬（平量）與衣長範圍，孩子可勾選預留成長空間
    - **對照尺寸表**：可直接編輯、套用範例（成人 XS～3XL 與兒童 110～150 為 LOGOless T恤尺寸表），或貼上直式（每列「尺寸 胸寬 衣長」）與橫式（商品頁常見的「XS S M…／胸寬 43 46…／衣長 64 67…」，兒童表的「110cm 120cm…」也可以）尺寸表；自動判斷是胸寬或胸圍，標示每個尺寸偏緊／偏鬆／偏短／偏長，相機量完立即顯示並念出建議尺寸
    - 影像只在瀏覽器本機運算不上傳；輸入的數字與尺寸表記在瀏覽器

## 使用方法

### 1. 開啟測驗系統
- 直接用瀏覽器開啟 `index.html` 檔案
- 或將整個資料夾放到Web伺服器上

### 2. 直接提供他人使用
- 可將整個專案資料夾直接壓縮成 ZIP 提供給他人
- 對方解壓縮後直接開啟 `index.html` 即可使用
- 若要線上分享，將整個資料夾部署到 GitHub Pages、Netlify、Vercel 靜態站點或一般 Web 主機即可

### 3. 選擇測驗科目
- 在首頁先選擇科目（如「資安概論」或「系統及網站滲透測試」）

### 4. 選擇測驗單元
- 於所選科目中選擇要測驗的單元
- 單選題與多選題分為兩個區塊
- 可選擇單一單元或全部單元綜合測驗

### 5. 進行測驗
- 每次僅顯示1題，可依需要調整每頁題數
- 點擊選項進行選擇
- 使用「上一題」/「下一題」按鈕切換頁面
- 可點擊題目左側星號進行收藏
- 使用「檢視答題狀態」按鈕快速切換題目
- 可隨時點擊「結束作答」提前提交

### 6. 查看結果
- 提交後自動顯示分數和正確率
- 正確答案會以綠色標示
- 錯誤選擇會以紅色標示
- 可點擊「下載結果PDF」取得含題目、答案與剩餘時間的報告
- 交卷後仍可使用上一題/下一題瀏覽，但答案將無法再修改

### 7. 重新測驗
- 點擊「重新開始」重新測驗同一單元
- 點擊「返回單元選擇」選擇其他單元
- 點擊「返回科目選擇」回到科目列表

## 自訂修改

### 修改題目
編輯 `quiz-data.js` 檔案中的 `quizData` 陣列：

```javascript
{
    "unit": "單元名稱",
    "questions": [
        {
            "question": "題目內容",
            "options": [
                "A) 選項A",
                "B) 選項B", 
                "C) 選項C",
                "D) 選項D"
            ],
            "answer": "B"  // 正確答案
        }
    ]
}
```

### 修改每頁題目數量
在 `quiz-app.js` 中修改 `questionsPerPage` 變數：

```javascript
this.questionsPerPage = 1; // 改為想要的數量
```
### 修改計時長度
在 `quiz-app.js` 中修改 `timeLimit` 變數（秒）：

```javascript
this.timeLimit = 30 * 60; // 30分鐘
```

### 新增/刪除科目與單元
1. 在科目列表點擊「新增科目」或「刪除科目」管理科目，刪除時以勾選方式選取可移除的科目。
2. 單元管理已整合到檔案管理區，可分別在「單選題庫」與「多選題庫」區塊使用「新增單元」或「刪除單元」按鈕，刪除時亦可勾選多個單元。
3. 新增後即可透過匯入功能加入題目，資料會儲存於瀏覽器。

### 匯入單選題庫
1. 在單元選擇畫面使用「匯入單選題庫」按鈕。
2. 選擇欲匯入的單元以及JSON格式檔案。
3. 檔案格式範例可下載 `import-format.json`。
4. 匯入的題庫將存放於瀏覽器 LocalStorage，重新整理後仍會保留。
5. 多選題庫可使用「匯入多選題庫」並套用 `import-multi-format.json` 格式。

### 匯出單選題庫
1. 在單元選擇畫面指定單元後，點擊「匯出單選題庫」即可下載JSON檔。
2. 多選題則使用「匯出多選題庫」下載。

### 編輯單選題庫
1. 在檔案管理區點擊「編輯單選題庫（刪除題目）」按鈕。
2. 選擇要移除的題目並確認，即可刪除該單元中的題目。

### 匯出/匯入全部題庫
1. 使用「匯入全部單選題庫」可一次導入所有單選題庫檔案。
2. 點擊「匯出全部單選題庫」下載目前科目所有單選題庫JSON。
3. 多選題庫亦可透過「匯入全部多選題庫」與「匯出全部多選題庫」批次處理。
4. 如需檔案範例，可分別下載 `import-format.json` 與 `import-multi-format.json`。

### 修改樣式
編輯 `index.html` 中的 `<style>` 區塊，或將CSS提取到獨立檔案。
